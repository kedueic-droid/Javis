# J.A.R.V.I.S. 鐵人指揮中心

Jarvis 風格的 **AI 應用入口 / 指揮中心**。原始碼放在 GitHub，正式環境以 **Firebase Hosting** 靜態部署。

這是一個不需後端的 SPA：Vite + React + TypeScript + Tailwind CSS + Three.js。五個既有應用以 **太陽系內圈行星** 接入指揮中心，不會改寫那些專案的原始碼。Grok Bot 的七名代理人是外圈 **AI 艦隊**：同頁橋接面板，不依賴公開網址。

主畫面是立體星系：中央發光球體是 **J.A.R.V.I.S. 核心（太陽）**，每個應用是繞行的行星。點選應用行星預設在同一頁內嵌開啟，不會自動另開分頁。點選艦隊晶體則開啟代理人橋接。

## 本機啟動指揮中心

```bash
npm install
npm run dev
```

瀏覽器開啟 [http://localhost:5200](http://localhost:5200)（刻意避開儀表板的 5173 與 Next.js 的 3000）。

```bash
npm run build      # 輸出到 dist/
npm run preview    # 預覽正式建置
```

## 把行星指到本機應用

指揮中心只負責 **啟動**，請先在各專案目錄自行跑起服務，再到本畫面「設定」填入網址。

| 應用 | 建議埠 | 預設網址 | 技術棧 |
| --- | --- | --- | --- |
| 健檢業績儀表板 | `5173` | `http://localhost:5173` | React + Vite + Tailwind + Firebase |
| 健檢業績週報 | `3080` | `http://localhost:3080` | Express + EJS + SQLite |
| 空島 Sky Island | `3000` | `http://localhost:3000` | Next.js + MapLibre |
| 檢驗報告數位工作台 | （Firebase） | 空白，請填 Hosting 網址 | 靜態 Firebase Hosting |
| 健檢方案組套工具 | `8501` | `http://localhost:8501` | Streamlit `app.py` |
| **本指揮中心** | `5200` | `http://localhost:5200` | Vite + React |

週報請使用 **3080**，避免與空島的 Next.js 搶 3000。

點應用行星（或側欄 MODULES）預設在 **指揮中心同頁內嵌舞台** 開啟，相機會輕輕對準該行星；可用拖曳把手調整星系區 / 內嵌區 / 側欄大小（尺寸會記在 localStorage）。舞台上的「外部開啟」才會另開分頁。若對方站台設了 `X-Frame-Options`，iframe 可能空白，請用「外部開啟」，系統不會自動跳新分頁。

## AI 艦隊

七名代理人（策略長、搬家執行長、陪病日執行長、商務長、業務副總、產品長、空島執行長）是內建名冊，不是自訂應用，也沒有穩定的公開聊天網址，所以不會塞進 iframe。

他們出現在三個地方，視覺上與儀表、週報同一套指揮語言，但外圈是晶體行星、標籤為金色：

- 星系外圈（圖例「外圈 · AI 艦隊」）
- 寬螢幕左側 MODULES 下方的 **AI 艦隊**
- 指令監視台（`/`）搜尋結果

點選後開啟同頁 **代理人橋接**：職務說明、可編輯的目前任務、一句可複製的「在 Grok Bot 側邊欄開啟同名代理人」，以及 `grokbot://app/v1/agent?id=…` 深連結複製鈕。任務筆記存在此瀏覽器的 `localStorage`（`jarvis.fleet.notes.v1`），與應用網址分開。重設應用預設不會清掉這些筆記。

指令監視台底部有 **派工給 AI 艦隊**：選擇代理人、寫入文字、排入本機佇列（待派）。「已送出」與「結果」目前只是佔位，這個靜態站不會呼叫 Grok Bot。之後要真正喚醒代理人，見 [docs/ai-fleet-bridge.md](docs/ai-fleet-bridge.md)。

## 新增第六個（或更多）應用

不需改程式：

1. 按右上角「設定」，或快捷鍵 `Cmd/Ctrl+K`、`/` 開啟指令監視台後選「新增應用」。
2. 填名稱、說明、網址、技術棧與圖示。
3. 「加入啟動器」後立即以新行星出現在星系中，並寫入此瀏覽器的 `localStorage`。

亦可「匯出 JSON」備份，或「匯入 JSON」還原。`重設為預設` 會清掉自訂項目並還原五個內建應用；AI 艦隊名冊、任務筆記與派工佇列不在這份 JSON 裡。

## Firebase Hosting 部署

1. 安裝 CLI：`npm install -g firebase-tools`
2. 編輯 [`.firebaserc`](.firebaserc)，把 `your-firebase-project-id` 換成你的專案 ID。
3. 登入並（若尚未建立）關聯專案：

```bash
firebase login
firebase use --add
```

4. 建置並部署：

```bash
npm run build
firebase deploy
```

[`firebase.json`](firebase.json) 已將 Hosting 的 `public` 設為 `dist`，並把所有路徑 rewrite 到 `index.html`，SPA 深層連結可直接開。

原始碼繼續用 Git 推到 GitHub；Hosting 只上傳 `dist` 靜態檔。

## 立體場景操作

主舞台是 WebGL **太陽系**：J.A.R.V.I.S. 為中央太陽，各應用為不同軌道半徑、速度與傾角的行星球體。拖曳空白處可環繞整個星系；拖曳行星可輕拉它離開軌道，鬆手後會彈回。

**如何開啟應用**

- 點選／點擊內圈行星：選取並在同頁投影（內嵌 iframe）
- 點選外圈晶體：開啟該代理人的橋接面板（不需要網址）
- 寬螢幕左側 **MODULES** 清單、指令監視台（`/`）亦可啟動
- 未設定網址或已停用的行星會改開「設定」
- 點太陽、雙擊星系空白處，或「操控場景」雙擊／`0`／`Home`：回到總覽視角

**相機**

- 拖曳星系空白處，或頂部 **「操控場景」** 手柄：環繞旋轉
- `Shift` 或滑鼠中鍵拖曳手柄：平移
- 滾輪、觸控板雙指開合、`Ctrl`（Windows）／`⌘`（macOS）+ 滾輪：縮放
- 單指拖曳亦可旋轉；雙指開合同時可縮放
- 手柄聚焦時方向鍵微調角度，`+`／`-` 縮放
- **內嵌 iframe** 與 **分隔線** 仍可獨立操作，不會被場景手勢搶走
- `prefers-reduced-motion` 會暫停（或接近靜止）行星公轉，但仍保留球體、軌道與深度；相機操作仍可用

## 陪伴光點與語音

全畫面有一枚全息光點跟著指標，帶一點彈簧阻尼，會落在游標右下方並看向指標，不會貼死游標，也不會擋住點擊（視覺層 `pointer-events: none`）。指標停住時它停在附近；游標離開視窗後會慢慢回到畫面中下方。系統開啟「減少動態效果」時，光點固定在待命位置。

右下角可以跟 J.A.R.V.I.S. 說話。辨識與朗讀使用瀏覽器的 Web Speech API（`zh-TW`），不需要 API 金鑰，本站也不會把音訊上傳到自己的伺服器。桌面版 Chrome / Edge 支援最完整；不支援時會顯示說明，星系與 AI 艦隊仍可使用。快捷鍵 `V`（輸入框以外）可開始或停止聆聽，「靜音」存在 `localStorage`（`jarvis.voice.muted.v1`）。

語音指令只在聲紋通過後才會執行。第一次要朗讀三句短語登錄主人聲紋；之後每次開口都會在瀏覽器裡用 ReDimNet-B2 取出聲紋向量，和本機 IndexedDB 裡的主人檔比對。分數低於門檻、尚未登錄，或聲音太短，都不會開啟模組或艦隊，並顯示「無法確認是您的聲音」。重新登錄與清除聲紋會先核對目前主人。模型約 22 MB，推理引擎約 11 MB，都從本站載入。細節見 [docs/companion-voice.md](docs/companion-voice.md)。

可說：打招呼、說明、現在幾點、艦隊概況、模組狀態、開啟設定、開啟某個模組或代理人、關閉。

## 操作說明

- 開機動畫約 2–3 秒，可按「略過」；設定可永久略過。
- 開機提示音使用 Web Audio，**預設靜音**。
- `Esc` 先關閉設定或指令監視台；若沒有浮層則關閉內嵌舞台。
- 系統會依時段顯示中文問候（早安 / 午安 / 晚安 / 深夜協議）。
- `prefers-reduced-motion` 會關閉掃描線、開機動畫，並暫停行星公轉，但仍保留立體球體與軌道。陪伴光點改為固定待命，不再跟隨指標。
- 手機可單指旋轉星系、點選行星啟動；寬螢幕另有左欄模組清單。內嵌時改為可拖曳分割版面，星系留在一側。
